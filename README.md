# OSINT Toolkit

A desktop GUI for organizing and launching publicly available OSINT tools.

## Features

* Modern Tkinter GUI
* Search and filter
* Categories - Tool
* Installation/status detection
* Tool descriptions
* Examples - Commands
* Direct links to official documentation
* Output window for launched tools

## Included tools

| Tool         | Category | Purpose                                                |
| ------------ | -------- | ------------------------------------------------------ |
| Sherlock     | Username | Finds publicly visible profiles using a username       |
| SpiderFoot   | OSINT    | Automated OSINT collection                             |
| theHarvester | Domain   | Collects publicly available domain information         |
| Recon-ng     | OSINT    | Modular OSINT framework                                |
| Amass        | Domain   | Domain and subdomain reconnaissance                    |
| ExifTool     | Metadata | Reads file metadata                                    |
| GHunt        | Accounts | Researches publicly visible Google account information |
| Nmap         | Network  | Network/service discovery                              |
| WHOIS        | Domain   | Domain registration information                        |
| dig          | DNS      | DNS queries                                            |

## Requirements

* Python 3
* Tkinter


## Usage

```bash
python src/osint_toolkit.py
```
